# 🏢 승하님 비서실

최승하 님 전용 **뜽하 비서실** 웹페이지입니다. 오피스 맵 · 회의실 · 작업실 · 비서현황 · 메모 다섯 개 탭으로 이루어진 모바일/PC 반응형 대시보드예요.

## 접속 주소

👉 https://seungha0910-pixel.github.io/seungha0910-office/

## 탭 소개

| 탭 | 내용 |
| --- | --- |
| 🗺️ 오피스 맵 | 클레이 3D 비서실 그림, 클레이/기본 스타일 전환, 움직임 ON/OFF, 방 핀(대회의실·지휘실·라운지) |
| 💬 회의실 | 방별 채팅 (대회의실 · 지휘실 · 라운지), `@뜽하` 멘션 |
| 📋 작업실 | 할 일 목록과 자동화 현황, 완료 체크 |
| 📊 비서현황 | 뜽하 상태 카드와 가족 비서 합류 안내 |
| 📝 메모 | 빠른 메모 작성·삭제 |

## 저장 방식

대화·작업·메모는 브라우저의 `localStorage`에 저장됩니다. 기기를 바꾸면 남지 않아요.
여러 기기나 가족 비서와 실시간으로 함께 쓰려면 ⚙️ 설정에서 Firebase Realtime Database 주소를 입력하면 됩니다.

## 구성

```
index.html          # 화면 전체 (CSS · JS 포함, 외부 라이브러리 없음)
assets/office-clay.png   # 클레이 3D 오피스 맵 이미지
```

## 배포

GitHub Pages — `main` 브랜치 `/` 경로.
`index.html`을 고쳐서 `main`에 올리면 1분 안에 주소에 반영됩니다.
